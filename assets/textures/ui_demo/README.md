# Original FRONTIER demo artwork

Eight PNG textures drawn procedurally for TurboGameEngine: six shaded planets,
one transparent orbital illustration and one four-cell white icon atlas.
No photographs, remote assets, Roblox artwork or third-party image material
were used. Reproduce with `python generate.py` (Pillow required).

The user's UI Demo project contains identical PNGs. `assets/ui_images.json`
maps local `rbxassetid://7001`–`7006`, `7100` and `7200` to these files. IDs are
project aliases and never cause a Roblox network request. The seventh Visual
tab demonstrates the actual native image/gradient/layout/input hosts.
