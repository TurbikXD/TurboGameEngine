# Проекты TurboGameEngine

При обычном запуске сначала открывается окно **Projects**.

- **Blank Project** — имя и папка размещения; **Create Project** создаёт новый
  каталог и открывает пустую сцену. Существующие папки проектов не заменяются.
- **Open Existing Project** — выбор файла `.tgeproj` или ввод пути к файлу/папке.
- **Recent Projects** — ранее открытые проекты; двойной щелчок открывает проект.
- **Engine Demo** — прежняя встроенная сцена и её ресурсы.

В Blank Project есть только служебная камера редактора. Объекты можно добавлять
через обычное меню Create, а скрипты — через Script Workspace. Команда
**Script → Lab 2: Collectathon + React UI** при необходимости импортирует
пример в ресурсы выбранного проекта, сохраняя уже существующие файлы.

**File → Save Scene** сохраняет сцену выбранного проекта. При следующем
открытии она загружается автоматически. **File → Switch Project...** возвращает
в Projects: **Save All & Switch** сохраняет сцену и открытые изменённые скрипты,
**Discard & Switch** закрывает их без сохранения, **Cancel** оставляет проект
открытым. Из Play сначала восстанавливается сцена Edit. Ошибка сохранения
оставляет проект открытым.

Новый проект содержит:

```text
MyProject/
  MyProject.tgeproj
  assets/
    scenes/main.scene.json
    scripts/
    prefabs/
    models/
    textures/
  .tge/editor_layout.json   # появляется при сохранении настроек редактора
```

Manifest — JSON версии 1:

```json
{
  "version": 1,
  "name": "MyProject",
  "assets": "assets",
  "startupScene": "assets/scenes/main.scene.json"
}
```

Пути в manifest относятся к каталогу проекта и должны оставаться внутри него.
Сцены, пользовательские ресурсы, Luau-модули, документы редактора и контекст
Codex принадлежат выбранному проекту. Совпадающие относительные имена ресурсов
в разных проектах используют разные ключи кэша. Служебные шейдеры и React Luau
поставляются с движком. Общий `config.json` по-прежнему настраивает окно и GPU.

В Windows начальная папка новых проектов — **Documents/TurboGameEngineProjects**;
её можно поменять в форме создания. Список последних проектов хранится в
**LocalAppData/TurboGameEngine/projects.json**. Повреждённый список не мешает
открывать проекты вручную. Поддерживаются русские имена и пути.

Явно включённые режимы лабораторного профилирования `TGE_LAB_SCENE` и
`TGE_STRESS_SCENE` сохраняют прежний автоматический запуск без селектора.

## Запуск игры

**Play in Editor** в верхней панели или меню **Scene** запускает скрипты и
физику внутри редактора. Во время игры доступны инспектор, gizmo, создание,
удаление, компоненты, параметры Luau и отдельная история Undo/Redo. Pause/Resume
приостанавливают/продолжают симуляцию. **Stop** возвращает сцену и историю
редактора к состоянию перед запуском; временные правки сцены не сохраняются на диск.
Сохранение файлов скриптов (**Save**, Ctrl+S или правки AI на диске) автоматически
применяется во время игры. **Save + Reload** также позволяет запросить обновление вручную.
Undo/Redo во время Play восстанавливает снимок сцены и заново запускает Luau-скрипты;
их внутреннее состояние `self.state` инициализируется повторно.

**Play Window** (меню **Scene → Play in Separate Window**) запускает отдельный
процесс с копией текущей сцены, включая несохранённые изменения. При переключении
из Play in Editor игра получает текущий снимок, а редактор возвращается в Edit.
Окно игры показывает 3D-сцену и игровой React UI без панелей, gizmo и контуров
выделения. **Esc**, крестик окна или **Stop Game** закрывают сеанс. Закрытие
редактора также завершает его игру; временные файлы сеанса удаляются.

## Live-редактирование

Оба режима наблюдают за файлами текущего проекта. Загруженные `.luau`/`.lua`
и потребители изменённых `require` обновляются автоматически, обычно через 0,3–0,6 с
после сохранения. Чтение файлов и компиляция выполняются в jobs, замена кода —
на основном потоке между шагами игры. Незавершённые записи от редактора/AI
ожидают стабилизации; ошибки синтаксиса или загрузки оставляют предыдущий рабочий код.
Диагностика доступна в Script Output и `logs/engine.log`.

Замена поведения сохраняет `self.state`, параметры компонентов, объекты и паузу.
`Init` повторно не выполняется. Для миграции состояния или изменений, которые раньше
делались только в `Init`, можно добавить `OnReload(self)` — он вызывается после
успешной замены. Новые объекты со скриптами получают обычный `Init`.

React-компоненты обновляются в существующих корнях UI, в том числе компоненты
из `require` и функции уровня модуля, захваченные `Init`/`Update`. При изменении
типа компонента он перемонтируется: локальное состояние hooks может сброситься,
а состояние игры в `self.state` сохраняется. Динамическую сборку UI внутри `Init`
можно перенести в `Update` или обновлять в `OnReload`.

Правки startup-сцены JSON также видны сразу в Edit и обоих Play: меняются только
изменённые свойства, добавляются/удаляются авторские объекты, сохраняются остальные
игровые объекты и их состояние. AI должен сохранять `sourceId` существующих объектов.
Отдельное окно начинает с несохранённого снимка редактора, затем наблюдает за исходной
startup-сценой проекта. Stop в редакторе по-прежнему возвращает снимок до Play;
изменённые AI файлы остаются на диске. Новые версии префабов используются при следующем spawn.

Открытые скрипты автоматически показывают внешние правки, если в документе нет
локальных несохранённых изменений. При конфликте локальный текст сохраняется,
а **Reload Disk** позволяет явно принять версию с диска.
