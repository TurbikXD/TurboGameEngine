## Методика

Три отдельных запуска на режим: ECS before/after и loading sync/async/legacy-pump — всего 15. Все завершились с кодами app/capture `0`. Порядок A/B чередовался, для трёх loading-режимов использована ротация. Прогрев 3 с после Tracy-маркера `LAB_RUN_START`; запись 15 с; основной диапазон +3…+14 с. Загрузка начинается на +6 с, её таблица использует отдельное одинаковое окно `LAB_LOAD_START −1…+5 с`.

В таблицах — **медиана метрик трёх прогонов**, а не объединение кадров. p95/p99 рассчитаны R-7 отдельно в каждом запуске. Max в общей таблице — медиана трёх максимумов; сами максимумы приведены ниже. Учитываются только полностью законченные зоны внутри диапазона. Все 15 прогонов сохранены.

Это неизолированная рабочая desktop-сессия: фоновые приложения пользователя не останавливались. Кэш файлов ОС не сбрасывался. Ротация и N=3 уменьшают влияние порядка, но результаты описательные; статистическая значимость и условия контролируемой лаборатории не заявляются.

Runner одинаково во всех режимах запускал приложение с `-WindowStyle Hidden`. `Main Frame` здесь — elapsed-время CPU-цикла и отправки рендера, **не измеренная задержка вывода на монитор**. Выводы о GPU time и display FPS из этой серии не делаются. Отдельно проверено видимое демо: [живой кадр loading](../../reports/lab1-defense/live-loading.png), 18 Ready / 0 Failed; условия готовой измерительной серии не менялись.

## Задача №2: подготовка матриц ECS

Фиксированная сцена — 4096 render-сущностей. `TGE_JOBS=0/1` меняет последовательную обработку snapshot на dispatch по диапазонам. Пул существует в обоих режимах; сравнивается использование задач этой системой.

| Метрика, мс | До | После |
|---|---:|---:|
| Render Prepare Transforms — mean | 2,790 | 0,925 |
| Render Prepare Transforms — median | 2,686 | 0,916 |
| Main Frame — median | 9,851 | 9,184 |
| Main Frame — p95 | 12,903 | 11,817 |
| Main Frame — p99 | 14,400 | 13,654 |
| Main Frame — медиана максимумов | 21,740 | 20,552 |

Среднее время целевой зоны сократилось на 66,8% (примерно 3,02×), медиана кадра — на 6,8%. Оставшаяся крупная последовательная зона `Render Submit`: mean после **5,497 мс**, против **0,925 мс** подготовки матриц. Ускорение одной стадии не означает трёхкратного ускорения всего кадра.

Максимумы Main Frame в прогонах 01 / 02 / 03: до **35,192 / 21,740 / 21,674 мс**, после **34,396 / 19,716 / 20,552 мс**. Трейсы одного повторения: [до 03](../../reports/lab1/release-verified/ecs-before-03/trace.tracy), [после 03](../../reports/lab1/release-verified/ecs-after-03/trace.tracy).

## Обязательная задача №1: загрузка ресурсов L1

Пачка настоящих ресурсов: 12 PNG 2048×2048 и 4 OBJ по 131072 треугольника; штатные декодер, парсер и GPU-финализация. Исходный движок **уже имел отдельный async-пул на 4 потока**. Он мигрирован в общую job system. `before` ниже — контролируемое отключение async для демонстрации L1, не утверждение о синхронности исходного движка. `legacy-pump` использует новый scheduler с практически снятыми лимитами пампа: это сравнение ограниченного и неограниченного drain, не старый бинарник.

| Main Frame / загрузка | Sync (`before`) | Async + ограниченный памп (`after`) | Async + `legacy-pump` |
|---|---:|---:|---:|
| Median, мс | 0,462 | 0,486 | 0,460 |
| p95, мс | 3,495 | 3,115 | 3,429 |
| p99, мс | 5,849 | 7,326 | 6,652 |
| Медиана максимумов, мс | 3410,838 | 30,003 | 72,152 |
| Медиана полных кадров внутри загрузки | 0 | 738 | 767 |
| Медиана длительности пачки по двум маркерам, мс | 3409,461 | 1109,204 | 1105,976 |

В async-режиме кадры продолжаются, пока ресурсы читаются/декодируются: по прогонам **852 / 672 / 738** полностью завершённых кадров между `LAB_LOAD_START` и `LAB_LOAD_COMPLETE`. В sync-режиме — **0 / 0 / 0**. Это непосредственно проверяется по временам зон и сообщений Tracy.

| Максимум кадра, мс | Прогон 01 | Прогон 02 | Прогон 03 |
|---|---:|---:|---:|
| Sync | 3447,073 | 3133,067 | 3410,838 |
| Async + ограниченный памп | 30,003 | 24,496 | **50,570** |
| Async + legacy-pump | 131,182 | 72,152 | 70,483 |

Секундная блокировка sync устранена в этих прогонах, но **отсутствие любых фризов не доказано**: async p99 вырос с 5,849 до 7,326 мс (+25,2%), а в `after-03` зафиксирован один кадр >50 мс. Число кадров >16,67 мс в loading-окне async — 3 / 6 / 6. Бюджет пампа 2 мс мягкий: уже начатый GPU-upload не прерывается; ограничение 1 ресурс/кадр не гарантирует длительность кадра ≤2 мс.

Трейсы: [sync 03](../../reports/lab1/release-verified/loading-before-03/trace.tracy), [async 03 с выбросом](../../reports/lab1/release-verified/loading-after-03/trace.tracy), [legacy-pump 03](../../reports/lab1/release-verified/loading-legacy-pump-03/trace.tracy).
