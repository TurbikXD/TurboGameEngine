# Маяк

«Маяк» — интерактивный стенд для защиты ЛР 5. Подключите питание, синхронизацию и телеметрию кнопками или клавишами **1**, **2** и **3**. Приёмники выходят на орбиту вокруг ядра, а на панели открываются аварийные пробы. **Esc** завершает игровой запуск.

Откройте `Lab5Beacon.tgeproj` в редакторе и нажмите **Play** для работы со сценой и её шагами. В поставке `Play-Lab5.cmd` открывает автономную игру с аварийными пробами. У пробы есть отдельное подтверждение. Первый релиз содержит **Integer divide by zero** и **Access violation**, второй добавляет **Assertion failure**.

Вкладка **Как устроен релиз** ведёт от сборки и двух архивов через аварийный отчёт к чтению стека. Последняя страница содержит порядок трёх запусков для защиты.

Для проверки наличия ресурсов в копии поставки можно переместить `game/assets/textures/beacon.ppm`. Эта текстура используется на вращающемся ядре и требуется тесту игрового пакета.
