# ЛР 2: «Лаборатория скриптов»

Отдельная интерактивная презентация-игра внутри TurboGameEngine. Восемь тем,
оглавление, Next/Prev, счёт посещённых тем и три ключа за реальные действия.
Автор и группа намеренно не указаны: подставьте свои данные при необходимости.

## Запуск Release через Projects

1. Запустите актуальный `C:/tge/profile/Release/app.exe` обычным способом.
2. В **Projects → Open Existing Project** выберите
   `demos/lab2-defense/Lab2Defense.tgeproj` или вставьте абсолютный путь к нему.
3. Нажмите **Play in Editor**. Интерфейс появится во **Viewport**.
   Настройки этого проекта скрывают боковые панели, включая Assistant.
4. Для защиты удобно **Play Window**: игра занимает отдельное окно без редактора.
   Рекомендуемый размер окна — от 1000×680; длинные темы и задания прокручиваются.
5. Навигация — кнопки оглавления, **Назад/Далее** или Left/Right, когда игровой
   Viewport принимает ввод. При работе в Script Workspace используйте кнопки UI.

**Stop** возвращает сцену к состоянию до Play и сбрасывает сессионный прогресс.
Вкладка Script/Viewport переключает код и презентацию. Если открыт Script
Workspace, вернитесь во Viewport после сохранения файла. Из отдельного Play
можно редактировать исходный файл в редакторе и затем вернуться в окно игры.

## Три задания

1. **Ключ архитектуры**, тема 02: ответить на три вопроса о границе C++/Luau.
   Ошибку можно исправить; очки не начисляются за один и тот же ответ повторно.
2. **Ключ ECS**, тема 04: создать три экземпляра `prefabs/marker.json`, затем
   переместить их. Выводятся реальные `id`, `getTag` и `getPosition`. Кнопка
   **Показать 3D-сцену** скрывает слайды; **Вернуться к защите** возвращает их.
   Только собственные `Lab2Marker` доступны кнопке очистки.
3. **Ключ непрерывности**, тема Hot reload: увеличить `self.state.counter`, зафиксировать
   его, затем без Stop открыть `scripts/ReloadRules.luau`, поменять `version`
   с `"A"` на `"B"` (или обратно) и нажать **Save**. Вернуться во Viewport.
   Ключ выдаётся только из настоящего `OnReload`: версия должна измениться,
   `counter` совпасть с контрольным, `Init` остаться равным 1. Если после фиксации
   ещё увеличить counter, контроль не пройдёт — зафиксируйте новое значение.

Тема React отдельно показывает настоящий `React.useState`. Его локальное состояние
может сброситься при remount; оно не используется как доказательство сохранения
состояния поведения. Тема 08 показывает фактически выполненные задания сессии.

## Что внутри

- `assets/scripts/Defense.luau` — навигация, UI, квиз, задания и жизненный цикл.
- `DefenseContent.luau` — таблица восьми тем, сгенерированная из общего
  `docs/lab2/defense/content.json`. `sync_content.py` переводит slides/lead в
  topics/summary, сохраняет station, notes, sources и appendix. После изменения
  JSON запустите `python demos/lab2-defense/sync_content.py`.
- `DefenseQuiz.luau` — три локальных вопроса и индексы правильных ответов.
  Станции quiz/spawn/reload определяются общим JSON; раздел «Сделано» собирается
  из заголовков тем, ограничения — из appendix.limits.
- `ReloadRules.luau` — небольшой безопасный файл для реального dependency reload.
- `Marker.luau` и `prefabs/marker.json` — реальные ECS-экземпляры с вращением.
- `assets/scenes/defense.scene.json` — собственная сцена, камера и контроллер.
- `assets/shaders_hlsl` — совместимые шейдеры, скопированные из ресурсов движка;
  `textures/white.ppm` — собственная белая текстура 2×2.
- `.tge/editor_layout.json` — настройки только этой демонстрации.

React, ReactTurbo и RobloxUI поставляются с движком. Нет внешних сетевых API,
учётных записей, npm, браузера и дополнительных C++ изменений. Текст использует
native ImGui-шрифт приложения; текущая конфигурация движка добавляет fallback
для кириллицы и греческого. `Font` RobloxUI является подсказкой, а не загрузчиком
произвольного шрифта из проекта.

## Проверки и честные ограничения

```powershell
# JSON, собственные пути и подготовка Luau bundle без выполнения:
python demos/lab2-defense/check.py --write-only

# Выполнение с уже имеющимся standalone Luau CLI:
python demos/lab2-defense/check.py --luau C:/path/to/luau.exe

# Либо с существующим CLI в Ubuntu WSL:
python demos/lab2-defense/check.py --wsl --luau /path/to/luau
```

Headless fixture использует настоящий vendored React/RobloxUI и отправляет
события в отрисованное retained-дерево: проверяет навигацию, hooks, квиз,
прикладные callbacks, контроль reload и unmount. `Engine` в этом fixture — явный
test double; `OnReload` вызывается напрямую. Это **не** проверка native ECS,
наблюдения за диском, GPU, шрифтов или доступности кнопок на экране. Их нужно
проверить в Release приложении по сценарию выше. Сгенерированный bundle находится
в игнорируемой `.tge/check/`; исходники движка и общие тесты не меняются.

Это UI facade и свой ECS, а не полный Roblox runtime. Нет native debugger,
доказанного FPS/профилирования и утверждений об автоматическом прохождении
тестов. Прогресс игры хранится до Stop; runtime-маркеры не нужно сохранять в сцену.
